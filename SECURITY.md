# Security and publication policy

This repository is intended to be public.

Before committing content, verify that it contains no:

- passwords, API keys, access tokens, or private URLs;
- client-identifying or privileged information;
- unpublished legal strategy or internal work product;
- personal data that is not already intentionally public;
- draft material marked for internal review.

If a credential is committed accidentally, revoke it immediately and remove it from the repository history before further publication.
