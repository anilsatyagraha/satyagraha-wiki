# Footer Link Decision

## Objective

Make every external link in the Satyagraha wiki footer open in a new browser tab without exposing the originating page to the opened site.

## Evidence

The maintained footer is injected into the Quartz footer package by `scripts/Patch Site Chrome 29-08-2026 14-05-00.mjs` during `postinstall`. Updating generated HTML or `node_modules` alone would not survive a clean dependency installation.

## Decision

- Add `target="_blank"` to every social, course, profile, messaging, newsletter, and legal-help footer link.
- Add `rel="noopener noreferrer"` to every such link.
- Keep ordinary internal wiki navigation in the current tab unless a separate requirement changes it.
- Record and validate the behavior in the canonical Master Prompt and the Satyagraha publishing skill.

## Risks and guardrails

- **Risk:** A future dependency installation restores the upstream footer. **Guardrail:** Keep the behavior in the deterministic post-install patch script.
- **Risk:** `target="_blank"` permits access to the opener in some environments. **Guardrail:** Always pair it with `rel="noopener noreferrer"`.
- **Risk:** A broad transformation changes internal links. **Guardrail:** Scope the attributes to anchors rendered by the footer component and test internal navigation separately.
- **Risk:** The patch script treats an older custom footer as complete. **Guardrail:** Its idempotency check must require the new-tab security marker, not merely the custom footer text.

## Validation

1. Run the footer patch twice to prove idempotency.
2. Build the complete Quartz site.
3. Inspect every generated HTML page containing a footer.
4. Require all footer anchors to contain `target="_blank"` and `rel="noopener noreferrer"`.
5. Confirm the expected footer-link count is consistent across pages.
6. Confirm no unrelated internal link acquired `target="_blank"`.

## Remaining uncertainty

External destinations can change independently. This decision validates link behavior and attributes, not the continuing availability or content of third-party destinations.
